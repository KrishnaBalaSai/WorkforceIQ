## 2\. Prompt History



The following entries summarize the main prompt topics used during development. They are reconstructed from available project conversations and are not guaranteed to be verbatim copies of every original prompt.



### Project Architecture and Planning

* Help design an AI-powered workforce retention intelligence platform.
* Suggest a suitable architecture for a workforce attrition prediction system.
* Help organize the backend, dashboard, machine learning, database, and testing components.



### Database and Data Engineering

* Help design a PostgreSQL database schema for workforce analytics.
* Review employee history, compensation, engagement, and retention-related database structures.
* Help generate synthetic longitudinal employee data.
* Identify data consistency and referential integrity issues.



### Machine Learning

* Help design a prospective employee attrition prediction pipeline.
* Explain point-in-time feature engineering and temporal data leakage prevention.
* Compare classification models for imbalanced attrition data.
* Help implement probability calibration using Platt scaling.
* Explain PR-AUC, ROC-AUC, Brier score, and model evaluation.
* Help implement SHAP-based model explainability.



### Backend and API Development

* Help develop REST APIs using FastAPI.
* Review API authentication and authorization.
* Help secure sensitive HR ground-truth data.
* Review intervention lifecycle and audit logging functionality.
* Help implement CSV and JSON data export functionality.



### Dashboard Development

* Help improve the Streamlit workforce analytics dashboard.
* Review executive overview and workforce analytics pages.
* Improve engagement analytics using dynamic survey data.
* Review intervention management and model explainability pages.
* Help resolve dashboard data and visualization issues.



### Testing and Debugging

* Help investigate Python and PostgreSQL errors.
* Review API integration and dashboard tests.
* Help resolve authentication and authorization test failures.
* Review test results and Python compilation.
* Help verify the final README and Git changes.



### Documentation and Submission

* Help prepare the project README.
* Review architecture and technical documentation.
* Help prepare the AI usage disclosure.
* Review submission requirements and known project limitations.
